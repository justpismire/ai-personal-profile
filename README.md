## 本地同步与版本记录

首次下载（需先安装 Git，且远程仓库已建立）：

```powershell
git clone https://github.com/justpismire/ai-personal-profile.git
cd ai-personal-profile
```

每次编辑前同步最新内容，编辑后检查并提交：

```powershell
git pull --ff-only
# 编辑 README.md
git diff
git add README.md
git commit -m "docs: update personal profile"
git push
```

查看历史与恢复已提交的修改：

```powershell
git log --oneline
git show <commit-sha>
git revert <commit-sha>
git push
```

将 `<commit-sha>` 替换为需要查看或撤销的提交编号。`git revert` 创建新的撤销提交，保留原始历史；遇到冲突时先解决冲突，再按 Git 提示继续。保持工作区干净后再撤销提交。

Git 仓库自带版本记录，无需额外开启；只有已提交的内容进入历史，本地尚未提交的编辑不会自动形成版本。避免强制推送或重写历史，以保留可追溯性。首次提交若提示缺少身份，请按 Git 提示配置本仓库的 `user.name` 和 `user.email`。
